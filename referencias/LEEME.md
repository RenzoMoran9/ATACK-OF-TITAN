# Imágenes de referencia

Pon aquí las imágenes con las que quieres comparar las capturas del juego (`png`, `jpg`, `webp`…).

Si el nombre empieza por el de una vista, `npm run capturas` las coloca al lado de esa captura en
`capturas/comparativa_<fecha>.html`:

| Vista | Ejemplos de nombre |
| --- | --- |
| tejado | `tejado.jpg`, `tejado-trost.png` |
| calle | `calle-empedrada.jpg` |
| muralla | `muralla-canones.jpg` |
| puerta | `puerta-shiganshina.jpg` |
| bosque | `bosque-arboles-gigantes.jpg` |
| titan | `titan-sonrisa.jpg` |
| jugador | `jugador-uniforme.jpg` |

Las que no coincidan con ninguna vista aparecen igualmente en la galería al final de la hoja.
